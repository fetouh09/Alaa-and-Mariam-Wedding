النشر المجاني على GitHub Pages (بدون بطاقة):
1. افتح github.com وسجّل دخولك.
2. أنشئ Repository جديد باسم Alaa-Mariam-Wedding واجعله Public.
3. اختر Add file > Upload files.
4. ارفع جميع الملفات المذكورة أعلاه من داخل المجلد، بحيث تكون بجوار index.html مباشرة.
   لا ترفع المجلد نفسه بدلاً من الملفات.
5. اضغط Commit changes.
6. افتح Settings > Pages، ثم Build and deployment: Deploy from a branch.
7. اختر Branch = main، و Folder = /(root)، ثم Save.
8. بعد تفعيل النشر، سيصبح الرابط غالباً:
   https://YOUR-USERNAME.github.io/Alaa-Mariam-Wedding/
